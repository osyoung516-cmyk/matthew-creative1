MATTHEW CREATIVE 홈페이지 — 처음 사용하는 방법

1) 미리보기
- 폴더 안의 index.html을 더블클릭하면 브라우저에서 열립니다.
- 인터넷이 연결되어 있으면 Pretendard 웹폰트가 자동 적용됩니다.

2) 사이트 구성
- index.html : 홈페이지 내용
- styles.css : 디자인/반응형 스타일
- script.js : 메뉴/스크롤 애니메이션
- assets/ : 사진 파일

3) 가장 먼저 확인할 것
- 전화번호: 010.2812.3289
- 이메일: osyoung_88@hanmail.net
- 쇼릴: https://youtu.be/zeRAFIDlxrA
- Google Drive 링크 2개
위 내용이 공개 홈페이지에 올라가도 되는지 최종 확인하세요.

4) 사진 교체 방법
- assets 폴더에 새 이미지를 넣은 뒤 index.html의 이미지 파일명을 바꿉니다.
- 예: assets/work-jeju-shilla.png

5) 무료로 공개하는 가장 쉬운 방법
A. Netlify Drop
- https://app.netlify.com/drop 접속
- 이 홈페이지 폴더 전체를 ZIP으로 압축
- ZIP 또는 폴더를 드래그앤드롭
- 임시 주소가 즉시 생성됩니다.

B. GitHub Pages / Cloudflare Pages
- 나중에 개인 도메인을 붙일 계획이면 이쪽도 좋습니다.

6) 도메인 예시
- matthewcreative.kr
- matthew-creative.kr
- matthewfilm.kr
실제 구매 가능 여부는 도메인 업체에서 확인해야 합니다.

7) 수정 요청 시
- 문구 수정, 사진 교체, 페이지 추가, 문의 폼, 카카오톡 연결,
  네이버 지도, 자체 도메인 연결용 구조까지 확장할 수 있습니다.
